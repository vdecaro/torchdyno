# Getting started

Let's get started with TorchDyno.

Each guide below builds a complete model and runs in seconds. Once you are
comfortable with the workflow, move to the [concept pages](../concepts/index.md) to see every part each level offers.

## Happy paths

<div class="grid cards" markdown>

-   **[1. Read out a reservoir](first-reservoir.md)**

    Compose an echo state network, fit its readout in closed form, and
    score its forecasts.

-   **[2. Train a model end to end](train-end-to-end.md)**

    Compose a classifier of sequences from a different cell and train
    every part of it by backprop.

-   **[3. Benchmark across seeds](benchmark-across-seeds.md)**

    Fit fresh models on several seeds and report every metric as a mean
    and a standard deviation.

</div>

!!! tip

    If you have not yet installed TorchDyno, refer to the [Installation](../install.md) page.
